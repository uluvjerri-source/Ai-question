# AI VERSUS

AI 할루시네이션 질문 비교 월드컵입니다.

## 사용 방법
- 좌우(모바일에서는 위아래)의 질문 중 하나를 선택합니다.
- 해설을 읽고 다음 라운드로 이동합니다.
- 질문 & 사진 편집 메뉴에서 나만의 질문 매치를 추가하거나 수정할 수 있습니다.

## 저장 방식
편집한 내용은 현재 브라우저의 localStorage에 저장됩니다. 다른 방문자와 편집 내용이 자동 공유되지는 않습니다.

## GitHub Pages
이 저장소의 `main` 브랜치에 변경 사항이 올라오면 GitHub Actions가 사이트를 배포합니다.
